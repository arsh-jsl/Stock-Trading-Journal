# Stock-Trading-Journal

## Project Overview

I have a deep interest in finance, specifically the stock market. This project focuses on building a Stock Trading Journal that allows investors to record their stock and options trades, track profits and losses, and evaluate their trading performance over time.

## MVP Features

- Record stock and options trades.
- Store ticker, entry price, exit price, quantity, and trade date.
- Automatically calculate profit and loss.
- Save and view previous trades.
- Add notes explaining the reasoning behind each trade.
- Calculate total profit/loss and win rate.

## Future Plans (V2.0+)

- Add a calendar showing daily trades and total profit or loss for each day.
- Track performance by options strategy, such as calls, puts, and spreads.
- Calculate average profit and loss for different stocks and options contracts.

## Tech Stack

- **Python:** Main programming language.
- **yfinance:** Retrieve historical stock prices and market data.
- **Pandas:** Organize and manage trade data.
- **Matplotlib:** Create charts to visualize trading performance.
- **NumPy:** Perform financial calculations.
- **CSV:** Store trade history.
- **Git and GitHub:** Version control and project management.
